# 기능 개발

합의된 범위를 가장 작은 동작 단위부터 구현한다.

## 흐름

1. 관련 기능명세·기술설계와 기존 코드를 읽는다.
2. 재사용 가능한 구조, 프로젝트 검사 명령, 변경 반경을 먼저 확인한다.
3. 미결정 때문에 결과가 달라지면 질문하고, 그 밖의 작은 선택은 기존 관례에 맞춘다.
4. 기술설계의 구현 순서에 따라 한 번에 하나의 검증 가능한 단위를 만든다.
5. 오류·빈 상태·권한·데이터 경계를 정상 흐름과 함께 구현한다.
6. 변경 반경에 맞는 기존 검사와 테스트를 실행하고 실패 원인을 고친다.
7. 명세 밖 작업은 섞지 않고 발견 사항으로 남긴다.

## 완료 보고

- 사용자에게 달라진 동작, 핵심 파일, 실행한 검사와 남은 위험만 압축해 전달한다.
