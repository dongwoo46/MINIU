# 미니미 커플 기록 앱 상위기획

## 1. 배경과 문제

- 대상 사용자:
  - 연애 중이며 서로의 취향과 추억을 기록하고 싶은 10~30대 커플
  - 바쁜 일정이나 장거리 연애로 자주 만나기 어려운 커플
  - 캐릭터 꾸미기, 기록, 감성적 소통을 좋아하는 사용자
- 관찰한 문제:
  - 연인에 대해 알게 된 소소한 정보(취향, 습관, 갖고 싶어 하는 물건)가 흩어져 사라지고, 기념일마다 다시 떠올려야 한다.
  - 못 만나는 시간에는 메시지 외에 애정을 남길 방법이 없어 연결감이 끊긴다.
  - 기록 자체는 결과물이 없어 계속 쓸 동기가 약하다.
- 아직 검증하지 않은 가정:
  - 사용자가 연인 정보를 서술형으로 꾸준히 쓸 만큼 기록 부담이 낮다고 느낄 것이다.
  - AI가 기록에서 뽑은 프로필과 아이템이 "내 연인답다"고 받아들여질 것이다.
  - 상대방 미니미 집 방문·포옹 같은 비동기 애정 표현이 실제 연결감으로 이어질 것이다.
  - 두 사람 모두 가입해 커플로 연결하는 진입 장벽을 넘을 것이다.
  - SNS 공유 이미지가 자발적 확산의 동력이 될 것이다.
  - 상대방에 관한 정보를 앱에 저장·AI 활용하는 것에 양측이 거부감 없이 동의할 것이다.

## 2. 목표

- 바꾸려는 상태:
  - 연인에 관한 정보와 추억이 부담 없이 한곳에 축적된다.
  - 축적된 기록이 개인화된 미니미·아이템·대화라는 눈에 보이는 결과물로 돌아온다.
  - 만나지 못하는 시간에도 방문·포옹·편지로 애정 표현이 오간다.
  - 자랑하고 싶은 귀여운 결과물이 남는다.
- 성공 신호:
  - 커플 연결 완료율, 가입 후 7일 내 첫 기록 작성률
  - 주간 기록 작성 수, 주간 미니미 방문 횟수
  - 편지 작성 및 답장 비율
  - AI 채팅 일일 사용률과 제한 도달률
  - 아이템 제안 승인률, 공유 이미지 저장·공유율
  - 7일 및 30일 재방문율

## 3. 방향과 대안

- 선택한 방향:
  - 사진에서 만든 비식별화된 캐주얼 일러스트형 미니미를 커플 관계의 대표 오브젝트로 둔다.
  - 기록은 서술형 무제한으로 열어두고, AI는 기록에서 구조화 프로필을 뽑아 채팅·아이템·공유 문구의 근거로만 쓴다.
  - 미니미 세계는 집 외관·정원·미니미·우체통으로 이루어진 단일 외부 씬으로 한정한다.
  - AI 채팅은 하루 20회로 제한하고 잔여 횟수를 화면에 노출한다.
  - AI 아이템은 구체적 사물·취향에 한정하고, 미니미가 착용하거나 들 수 있는 형태만 허용한다.
  - AI 산출물(프로필, 아이템)은 항상 사용자가 수정·삭제할 수 있고 근거 기록으로 되짚을 수 있다.
- 선택 근거:
  - 실사 복제는 초상 리스크와 불쾌한 골짜기가 크고, 캐주얼 일러스트는 커스터마이징 여지가 넓다.
  - 기록 입력을 폼으로 쪼개면 작성 부담이 커져 축적 자체가 멈춘다.
  - 집 내부까지 열면 씬·에셋·인터랙션 물량이 2인 규모를 넘어선다.
  - AI 채팅은 호출당 비용이 발생해 상한 없이는 운영이 불가능하다.
  - "설렘" 같은 추상 감정은 아이템으로 그려도 알아볼 수 없고 착용 형태로 환원되지 않는다.
  - AI가 틀린 정보를 프로필로 굳히면 관계 데이터라 피해가 크다.
- 기각한 대안:
  - 연인 사진을 실사에 가깝게 복제하는 캐릭터 (초상·프라이버시 리스크, 커스터마이징 난이도)
  - 집 내부 방·가구 배치까지 확장하는 공간 (MVP 범위 초과)
  - 무제한 AI 채팅 (비용 통제 불가)
  - 추상적 감정 기반 아이템 생성 (해석 불가, 착용 형태 불성립)
  - 커플 연결 없이 혼자 쓰는 단독 모드 (상대방 소재 기록은 관계 정보라 연결 전 사용을 막는다)

## 4. MVP 범위

- 포함:
  - 초대 링크 또는 코드를 통한 커플 연결과 상대 정보 저장·AI 활용 동의
  - 사진 기반 미니미 생성 및 기본 커스터마이징(헤어, 피부톤, 얼굴형·표정, 의상 컬러, 이름)
  - 무제한 서술형 기록(선택 입력: 날짜, 사진, 장소, 태그, 기념일 여부)
  - AI 기반 프로필 요약, 근거 기록 연결, 사용자 수정·삭제
  - 일일 20회 제한형 미니미 AI 채팅과 가상 캐릭터 고지, 안전 응답 정책
  - 집 외관·정원·미니미·우체통으로 구성된 단일 외부 씬
  - 포옹·뽀뽀·쓰다듬기·손잡기·응원 남기기 등 기본 방문 인터랙션과 알림·활동 피드
  - 편지 작성·수신·답장, 읽지 않은 편지의 우체통 상태 표현
  - 취향 기반 착용 아이템 제안·승인·인벤토리, 집 색상 등 단순 꾸미기
  - D-day 선택을 포함한 공유 이미지 저장
- 제외:
  - 계절별 집 테마
  - 음성 편지
  - 미니게임
  - 아이템 컬렉션(도감·수집 체계)
  - 프리미엄 대화 이용권 등 유료 추가 이용권
  - 집 내부 공간 이동
  - 커플 외 제3자 방문·공개 피드

## 5. 파생 기능

| 기능 slug | 목적 | 우선순위 | PRD 상태 |
|---|---|---|---|
| `couple-connect` | 초대 코드·링크로 커플을 연결하고 상대 정보 저장·AI 활용 동의와 권한을 정한다 | 1 | 미작성 |
| `minimi-creation` | 사진으로 비식별화된 미니미를 생성하고 외형을 커스터마이징한다 | 1 | 미작성 |
| `record-ai-profile` | 서술형 기록을 쌓고 AI가 취향·습관·선물 힌트를 프로필로 구조화한다 | 1 | 미작성 |
| `minimi-chat` | 프로필과 기록을 근거로 상대방 미니미와 일일 제한 대화를 한다 | 2 | 미작성 |
| `minimi-house-visit` | 단일 외부 씬에서 상대 미니미 집을 방문해 애정 표현을 남긴다 | 2 | 미작성 |
| `mailbox-letter` | 우체통에 편지를 남기고 수신·답장·보관한다 | 2 | 미작성 |
| `ai-item-inventory` | 취향 기반 착용 아이템을 제안·생성하고 인벤토리에서 착용한다 | 3 | 미작성 |
| `sns-share-image` | 미니미 씬과 대표 문구, D-day를 한 장의 공유 이미지로 저장한다 | 3 | 미작성 |

## 6. 가정과 미결정

| 질문·가정 | 영향받는 기능 |
|---|---|
| 이별 또는 커플 연결 해제 시 공유 기록·편지·상대 미니미·프로필에 대한 접근을 어떻게 처리하는가? (즉시 차단 / 열람만 유지 / 유예 후 삭제) 원문은 "정책을 마련한다"까지만 명시했다 | couple-connect, record-ai-profile, mailbox-letter, minimi-house-visit |
| 커플 중 한쪽만 탈퇴하면 남은 쪽의 미니미·기록·편지는 유지되는가, 함께 소멸하는가? | couple-connect, record-ai-profile, mailbox-letter |
| 초대 코드·링크의 만료 시간과 재발급 규칙은? 만료 없이 무기한 유효한가? | couple-connect |
| 미니미 생성에 쓰는 사진의 업로드 매수 상한과 원본 사진 보관 기간은? (생성 직후 파기 / 재생성 위해 보관) | minimi-creation |
| AI 미니미 생성·아이템 생성이 실패하거나 부적절한 결과를 낼 때 재시도 횟수와 대체 경로(기본 캐릭터 제공 등)는? | minimi-creation, ai-item-inventory |
| 기록 1건에 첨부 가능한 사진 매수와 용량 상한은? | record-ai-profile |
| AI 채팅 일일 20회 제한의 리셋 기준 시각과 기준 시간대는? 커플 단위인가 사용자 단위인가? | minimi-chat |
| 방문 애정 표현에 하루 횟수 제한이나 알림 묶음 처리가 필요한가? (알림 피로 방지) | minimi-house-visit |
| 아이템 생성 조건(기록 10개 이상, 동일 취향 2회 이상 언급)은 확정 수치인가, 초기 튜닝 대상인가? | ai-item-inventory |
| 공유 이미지에서 미니미 이름·D-day 노출을 어디까지 기본값으로 허용하는가? | sns-share-image |
| 데이터 암호화·삭제·내보내기 정책의 구체 범위(내보내기 포맷, 삭제 유예 기간)는 MVP에 포함되는가? | couple-connect, record-ai-profile |
